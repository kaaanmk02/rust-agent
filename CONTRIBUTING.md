# Contributing to rust-agent

Thank you for your interest in contributing.

## Quickstart
```bash
git clone https://github.com/kaaanmk02/rust-agent.git
cd rust-agent
./scripts/setup.sh
cargo test
```

## Ground rules
- Keep changes minimal and reviewable; avoid large refactors without discussion.
- Do not add API keys, tokens, or credentials.
- Make sure `cargo test` passes before opening a PR.

## Commit style
Use imperative, present tense: `Add chat CLI`, `Fix middleware auth`.
